日本語

my-assistant(以下「本プログラム」)は、開発者本人が自分のサーバーで動かしている個人用のプログラムです。利用者は開発者本人だけで、ほかの方の情報を扱うことはありません。

アクセスする Google のデータ

本プログラムは、開発者本人の許可にもとづき、次のデータを読み取り専用で取得します。

  • Google カレンダー: 対象日の予定(カレンダーの読み取り権限 calendar.readonly)
  • Google ToDo リスト: 対象日のタスクと、期限切れで未完了のタスク(タスクの読み取り権限 tasks.readonly)

予定やタスクを作成・変更・削除することはありません。

データの使い方

取得した予定とタスクは、開発者本人宛てのメールを作成するためだけに使います。メールは Gmail を通じて、開発者本人に送信します。

  • 第三者への提供: 取得したデータを第三者に提供・販売しません。
  • AI サービス: 予定とタスクを AI サービスに送信しません。AI の学習にも使用しません。
  • 広告・解析: 広告や解析の目的には使用しません。

本プログラムによる Google API から取得した情報の使用は、Google API サービスのユーザーデータに関するポリシー(限定使用の要件を含む)に従います。

データの保存

  • 予定とタスクの内容は、データベースに保存しません。動作確認のときだけ、開発者本人のサーバーにメールのプレビューファイルを作成します。送信したメールは、開発者本人のメールボックスに残ります。
  • Google へのアクセスに必要な認証情報は、開発者本人のサーバーに、本人だけが読める形で保存します。

アクセスの取り消し

本プログラムへの許可は、Google アカウントの「サードパーティ製のアプリとサービス」からいつでも取り消せます。

本ポリシーの変更

本ポリシーを変更する場合は、このページで告知します。

English

my-assistant ("the Program") is a personal program the developer runs on their own server. The developer is its only user, and it does not handle anyone else's information.

Google Data Accessed

With the developer's own authorization, the Program retrieves the following data on a read-only basis.

  • Google Calendar: events on the target day (read-only scope calendar.readonly)
  • Google Tasks: tasks due on the target day and overdue incomplete tasks (read-only scope tasks.readonly)

The Program never creates, changes, or deletes events or tasks.

How the Data Is Used

Retrieved events and tasks are used only to compose an email to the developer, which is sent to the developer through Gmail.

  • Third parties: The data is not shared with or sold to third parties.
  • AI services: Events and tasks are not sent to AI services and are not used to train AI models.
  • Advertising and analytics: The data is not used for advertising or analytics.

The Program's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Data Storage

  • Event and task contents are not saved to a database. A preview file of the email is created on the developer's own server only during testing. Sent emails remain in the developer's own mailbox.
  • The credentials needed to access Google are stored on the developer's own server, readable only by the developer.

Revoking Access

Authorization can be revoked at any time from "Third-party apps & services" in the Google Account.
